# Solution-First Learning Workflow (for DSA & Hard Engineering)

When learning complex patterns (e.g., DSA) where deriving from scratch creates prohibitive friction, use the **Solution-First (Pattern Absorption) Method**. The goal is not "solving" but "absorbing the pattern."

## The Procedure
1. **Analyze (15-20 min):** Spend time reading, sketching the brute force, and identifying inputs/outputs. **Do not code yet.**
2. **First-Principles Peek (If Stuck):** If comprehension hits a wall, ask the AI for:
   - **Hints ONLY** (not the solution) on how to approach the pattern.
   - **Visualizations** (e.g., HTML/SVG memory diagrams) of how the data structure/pointers move.
3. **Attempt (15 min):** Try to implement the pattern based on the hints.
4. **Absorption (If Failing):** If still stuck, ask the AI for the **full solution + visualization**. 
5. **The Non-Copy Rule:** **NEVER copy the code.** Close the solution. Write the solution out entirely from scratch based on the visualization and the pattern you just absorbed.
6. **Pattern Audit (Cold Redo):** After 3 days, revisit the problem and solve it **cold** (no peeking). If you fail this, add it to a "Redo List."
